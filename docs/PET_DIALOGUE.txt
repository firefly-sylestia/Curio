CURIO — PET DIALOGUE REFERENCE (edit-friendly)
================================================================================
Every line the Curio pet (and the tour guide) says, grouped by WHEN/WHY it
appears, with the exact code location so you can find and polish each one.

Legend
  • [picks one at random]  = the pet shows ONE line from that group per event
  • __LANE__               = replaced at show time with a category name
  • (caption)              = my note on what the line is FOR, not spoken text

Notes for future edits
  • Keep one sentence per passive bubble (the pill shows max 2 lines).
  • The TOUR dialogue is NOT capped at 2 lines anymore: PetSpeechBubble
    takes maxLines/maxWidth, and the tour passes unlimited lines + 340dp.
  • Try to avoid em dashes (—) in user-facing copy; use "…" or plain text.
  • Lines are picked at random per group — to change the mood, edit the
    matching group in CurioPet.kt (section headers name the list variable).
  • The pet's REACTION TIMING (how long a bubble stays up) lives in
    CurioFloatingPet.kt: hold ≈ 2.3s + fade, dizzy recovery 2.5s.
  • New lines added to a pool automatically respect the anti-repeat bag
    (pickLine) — no extra wiring needed.
