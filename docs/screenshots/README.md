# README screenshots

This folder holds the app screenshots embedded in the root `README.md`
("Screenshots" section). The images themselves are not committed yet —
capture them from the app, name them exactly as below, and drop them in
this folder. The README links resolve as soon as the files exist.

## Files to add

| File name | Screen to capture |
|---|---|
| `home.png` | Home — hero with Streak · Cabinet · Topics stats and lane chips |
| `spin.png` | Spin — the shuffle deck with front ticket + 2 peek cards |
| `topic-reveal.png` | Topic reveal — explore action with the share pill visible |
| `capture.png` | Capture — a paper-textured editor (ruled lines, torn edge) |
| `cabinet.png` | Cabinet — library grid with category chips |
| `entry-detail.png` | Entry detail — a saved entry with hero card and metadata |
| `quests.png` | Quests — daily quest trio with XP bar and pet |
| `share-card.png` | A finished share card (any Signature style, 3:4) |

## Capture guidance

- Portrait phone frames, 9:19.5-ish aspect (a normal phone screenshot is fine).
- PNG format, same file name as the table (lowercase, hyphens).
- Use the **Demo content for store screenshots** experiment
  (Settings → Experiments) so shots show rich sample data instead of a
  fresh install.
- Light theme (Curio default) for consistency; avoid personal data in
  captures.

## After adding images

Add them to git (`git add docs/screenshots`) — they ride to GitHub with
the next push and render in the README automatically. No README edit is
needed; the embeds already point at these paths.
