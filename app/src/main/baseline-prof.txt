# Curio — starter baseline profile (v331).
#
# Manually-authored HRF (human-readable profile) rules. AGP bundles this file
# into assets/dexopt/baseline.prof and ProfileInstaller (already present
# transitively via Compose, see the "Skipping profile installation" logcat
# line) installs it on first launch so ART AOT-compiles these classes at
# install time instead of JIT-compiling them at runtime.
#
# Why: the 2026-09-03 logcat showed the JIT compiling giant single methods
# (e.g. the 30-arg share-card / category-picker composables) at up to
# 7.7 MB of compiled code each, plus a ~6 MB "Compiler allocated" spike per
# method — a real memory/CPU cost on first runs, worse on low-RAM devices.
# These rules AOT-compile the same methods once at install.
#
# Release builds run R8 (minify ON): AGP rewrites these source-symbol rules
# through the R8 mapping automatically, so source names are correct here.
#
# Keep in sync with the app's actual hot paths; extend with a
# Macrobenchmark-generated profile if one is ever added.
